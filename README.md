# KakoiiHitos-FPS-System 
>An open source FPS system built in the vision of KakoiiHito, imagining what a good shooter system should be. The system is an easy to implement plugin.

## Features
>* Basic Player Movement and Camera Control
>* Dummy
>* 2 Weapon Gun System
>* Throwable System
>* Functioning Doors
>* Baseplate
>* Reusable Levels and Objects
